# Wasla — Jobs Platform Demo

A job-board front end for the Chadian market in a single HTML file: searchable listings, city and type filters, job detail modal, apply action, and a post-a-job form that publishes instantly. No dependencies.

![Stack](https://img.shields.io/badge/stack-vanilla%20JS-c8f542) ![Deps](https://img.shields.io/badge/dependencies-0-c8f542)

## Features

- **Listings** with company marks, salary, location and type
- **Search + filters** — free text, city (N'Djamena, Moundou, Sarh, Abéché, Remote) and employment type
- **Job detail modal** with an apply action
- **Post a job** — validated form (title, company, city required), new listings appear at the top
- **Responsive** card layout

## Run it

```bash
open index.html
```

Demo listings only. The full platform pairs this with an Android app and a backend for accounts, applications and employer dashboards.
